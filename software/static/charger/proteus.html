ทำเป็นไฟล์ Proteus

ไฟล์ .pdsprj ต้องสร้างในโปรแกรม Proteus เอง ทำตามขั้นตอนนี้จะได้ครบทั้งหน้า Schematic, PCB Layout และ 3D Visualizer ในไฟล์เดียว

  1. Schematic Capture

    กด P แล้วค้นชื่ออุปกรณ์ตามคอลัมน์ "ชื่อใน Proteus" ในหน้ารายการอุปกรณ์ วางทุกตัวแล้วตั้ง Ref ให้ตรงกับแบบ (R1, C1, U2 …) จากนั้นเดินสายตามผังวงจร หรือใช้ Terminal Mode วาง Default terminal แล้วตั้งชื่อเดียวกัน เช่น VREG, BAT+, A0

  2. Arduino Nano

    ถ้าไลบรารีมี Arduino Nano ให้ใช้ตัวนั้น ซึ่งใส่ไฟล์ .hex จำลองได้ ถ้าไม่มี ให้ใช้ CONN-SIL15 สองตัวแทนขา 2 แถว ระยะห่างแถว 15.24 มม. (600 mil) ได้ footprint ตรงกับ Nano จริง ส่วนจอ LCD ในหน้า PCB ให้ใช้ CONN-SIL4 (J4)

  3. ตรวจ Package ทุกตัว

    อุปกรณ์จำลองบางตัว เช่น BUTTON และ JHD-2X16-I2C ในไฟล์เดิมของคุณ มี Package เป็น NULL จึงไม่โผล่ในหน้า PCB ให้ดับเบิลคลิกแล้วเลือก PCB Package หรือใช้ชิ้นส่วนที่มี footprint แทน จากนั้นสั่ง Tools → Electrical Rule Check ต้องไม่มี error

  4. PCB Layout

    เลือกเลเยอร์ Board Edge วาดสี่เหลี่ยมขนาด 101.6 × 81.3 มม. วางอุปกรณ์ตามตารางพิกัดในหน้า PCB Layout หรือใช้ Auto-placer ตั้ง Design Rules ดังนี้: ลายสัญญาณ 0.5 มม., ลายไฟ 1.2 มม., ระยะห่าง 0.3 มม. แล้วสั่ง Auto-router หรือเดินลายเองตามรูป

  5. 3D Visualizer

    ในหน้า PCB Layout เปิดเมนู Output → 3D Visualizer อุปกรณ์ที่มี Package จะขึ้นเป็นโมเดล 3D ให้เอง

  6. ส่งผลิต

    Output → Generate Gerber/Excellon Files แล้ว zip ไฟล์ส่งโรงงาน PCB เลือกบอร์ด 2 ชั้น หนา 1.6 มม. ทองแดง 1 oz
